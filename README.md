# Advanced Machine Learning: labs

Lab material for the Advanced Machine Learning course (UNIMIB). Each lab is a set of Jupyter notebooks that run in Google Colab; nothing to install.

## How to open a notebook

Click its "Open in Colab" badge (in the lab README, or at the top of the notebook). The default CPU runtime is enough.

## Keras or PyTorch

The lectures use Keras. Every notebook comes in a Keras and a PyTorch version. They are equivalent: pick one and stay with it.

## Layout

- `lab1/`: Lab 1 (optimization): README, notebooks, competition data, 3D optimizer demo.
- `client/aml_client.py`: small client for the class server, downloaded by the notebooks.
